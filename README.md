# STM32 UART Parser Project

## Board
STM32 Nucleo-F446RE

## IDE
STM32CubeIDE

## Purpose
Practice UART RX architecture using ISR + ring buffer + parser + application command queue.

## Build
Open in STM32CubeIDE and build the Debug configuration.

## Current status
- UART RX interrupt working
- Parser detects complete packets
- Command queue integrated
